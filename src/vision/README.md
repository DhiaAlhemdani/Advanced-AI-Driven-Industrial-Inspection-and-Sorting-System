# Computer-vision implementation boundary

Place the **original** training, inference, preprocessing, and model-export files here when they are supplied by the project owner. Preserve their provenance and cite the exact thesis section or commit in [`docs/source-integrity.md`](../../docs/source-integrity.md).

The current checkout contains no original vision implementation. Do not infer the model family, augmentation policy, confidence threshold, IoU threshold, preprocessing, or training seed from the dataset description alone. The dataset inventory utility under `src/industrial_inspection/` is a curation aid, not a reconstructed inspection pipeline.
