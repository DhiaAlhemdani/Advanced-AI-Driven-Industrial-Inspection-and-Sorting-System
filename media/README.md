# Media artifacts

This directory contains one prototype photograph, two dashboard/conveyor screenshots, a Kaggle banner, and a demo video. Dimensions, sizes, hashes, and inspection notes are listed in [`../docs/artifact-inventory.md`](../docs/artifact-inventory.md).

Media supports an engineering narrative and provides qualitative evidence of a prototype/UI. It is not a substitute for source code, a wiring diagram, synchronized timestamps, an item-level route ledger, or raw model-evaluator output. Counters and health values visible in screenshots must not be aggregated into accuracy claims.

Large future media should use Git LFS or a release/external store; avoid committing private locations, credentials, or identifiable bystanders.
