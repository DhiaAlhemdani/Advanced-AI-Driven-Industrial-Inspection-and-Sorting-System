## Repository boundaries

The repository intentionally keeps these artifacts external on Kaggle: training images, detection labels, segmentation labels, LabelMe annotations, `metadata.csv`, the original notebook export, and model weights. Only small configuration snapshots and the uploaded benchmark outputs are retained here. See [`artifact-storage.md`](artifact-storage.md).
